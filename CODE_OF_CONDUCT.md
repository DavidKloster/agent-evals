# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in every project space: issues, pull requests, discussions, reviews, and when someone represents the project elsewhere.

In short: be welcoming, be kind, accept criticism of your work gracefully, and focus on what is best for the people who use and build this project. Harassment, insults, personal or political attacks, and publishing others' private information are not acceptable.

## Reporting

Report behaviour that breaks this code of conduct to the maintainer, David Kloster, at **kloster.davidjonas@gmail.com**. Every report is read, kept confidential, and answered. The maintainer applies the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction, warning, temporary ban or permanent ban, depending on the impact.

If the report concerns the maintainer, write to GitHub instead through [its reporting form](https://support.github.com/contact/report-abuse).
